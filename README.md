# How to Run
1. Download or clone my project (https://github.com/Kabir-khadka/signup-automation.git)
2. Run "npm install" command in the terminal
3. Run "npm start" to see the automation.

## Environment/Setup
- **Language**: JavaScript (Node.js)
- **Framework**: Selenium WebDriver (with Mocha for reporting)
- **Driver**: Selenium Manager (Automatically handles ChromeDriver versions, no setup needed)

## Test Data & Accounts Used
- **Email**: `vritqa.test2025@gmail.com` (Uses dynamic plus-addressing for unique account creation on each run)
- **OTP**: Automatically retrieved via IMAP login in the background
- **Phone**: Dynamically generated in `98XXXXXXXX` format
- **Document Upload**: `assets/shared_image.jpg`
